## Decisions and alternatives
- Analysed lighthouse-results/rev-004-devtools first: Style & Layout 988 ms > Script Evaluation 915 ms; forced-reflow insight 920 ms unattributed; long tasks on the document (896 ms) and chunk 216iyidhmrh3u.js (577 ms).
- Our components force no layout: MotionEnhancer uses IntersectionObserver only; SiteMenu reads layout only on interaction. A Chrome trace (4x CPU) confirmed the cost is the first full Layout (274 objects), with no JS stack.
- Probes on copies of the exported HTML isolated the cause. Replacing the symbol glyphs cut the first layout ~28%; disabling the web font did nothing. Conclusion: system font-fallback lookup for glyphs not in Cormorant/Arial (Windows Chrome, this machine). The cost on Android/iOS is not measured.
- Chose inline SVG over a symbol subset font: no extra request, consistent rendering, no emoji presentation risk.
- Not done: reducing React/Next runtime evaluation (the largest TBT term). That needs fewer or lighter client components or a framework-level change, and falls under ADR-0001 scope.
