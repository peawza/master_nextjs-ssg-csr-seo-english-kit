## Decisions and alternatives
- Wrangler runs in a pinned container instead of being added to package.json: keeps app dependencies minimal (AGENTS.md) and the token out of the build. Token is passed as `docker run --env NAME` (no value in argv).
- Default target preview; production needs `DEPLOY_TARGET=production` and `--confirm-production`, so a stray .env value cannot publish. noindex is never touched (SEO-008).
- Artifact is rebuilt every run and deleted on failure, so an old artifact cannot be uploaded.
- Preview exit codes 130 (Ctrl+C) and 143 (`docker stop`) treated as normal stop.
- No ADR: deployment tooling only; rendering/hosting model (ADR-0001) unchanged.
