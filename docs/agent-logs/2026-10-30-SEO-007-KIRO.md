## Decisions and alternatives
- Next metadata merge is shallow (verified in the official generateMetadata docs, "Merging"), so the helper always returns a full `openGraph` object. Twitter tags are left derived from OG by Next instead of being duplicated.
- Root `not-found` supports `metadata` (official not-found docs). Next types allow `null` for `canonical`, `openGraph` and `robots` (checked in node_modules/next/dist/lib/metadata/types). Clearing `robots` leaves only Next's injected `noindex`. `follow` is the default, and `X-Robots-Tag: noindex, follow` still applies to all paths.
- No ADR: static-only metadata, no change to rendering boundaries. Static export compatible; build shows all routes as Static.
