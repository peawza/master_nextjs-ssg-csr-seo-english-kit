- Relevant request / acceptance criteria: User asked (Thai) "deploy with Docker". Acceptance:
  1. A multi-stage Docker image builds the Next.js static export (`out/`) and serves it with a static web server - no Node.js runtime in the final image (keeps ADR-0001 static-export model).
  2. Security headers from `public/_headers` are served identically by the container.
  3. `trailingSlash: true` routes (`/services/`), `robots.txt`, `sitemap.xml` and the custom `404.html` (HTTP 404) behave correctly.
  4. Container runs as non-root, has a healthcheck, and is started locally via `docker compose`.
  5. Verified with real HTTP requests against the running container.
