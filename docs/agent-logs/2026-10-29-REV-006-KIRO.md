## Decisions and alternatives
- Attribution by marker strings in out/_next/static/chunks: React DOM + router core 71.9 KB gz, Next router 45.3 KB gz, our components ~2 KB net. noModule polyfills 39.6 KB are not executed by modern browsers.
- E1 (no client components) gave no measurable TBT change, so no component-level optimisation is worth shipping.
- E2 (all framework JS stripped from a copy) gives TBT 0, so the whole cost is App Router runtime + hydration.
- The only Next-native zero-JS route mechanism is Pages Router `unstable_runtimeJS: false` (unstable, undocumented; no App Router equivalent per vercel/next.js discussion #75230). Recorded as option B in ADR-0003, not implemented.
- Medians re-checked against raw runs; the E0 TTI median was corrected to 3737 ms before publishing.
