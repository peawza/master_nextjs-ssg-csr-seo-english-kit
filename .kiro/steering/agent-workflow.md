# Agent Handoff and Logging

At the beginning of each implementation task, inspect `docs/PROJECT_STATE.md`, relevant task logs and `git status`. Log the scope and test plan before changes. At the end, update `docs/agent-logs/YYYY-MM-DD-TASK-ID-KIRO.md` and `docs/PROJECT_STATE.md`. Include exact commands and measured test results. Never fabricate a Lighthouse audit. Follow `AGENTS.md` if details differ.
